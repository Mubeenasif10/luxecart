# LuxeCart – Modern E-Commerce Website

A modern, responsive e-commerce storefront built with React and Vite. LuxeCart provides a clean shopping experience with product discovery, filtering, sorting, wishlist management, shopping cart functionality, and a demo checkout experience.

## 🌐 Live Demo

**[Visit LuxeCart](https://luxecart-m.netlify.app/)**

## ✨ Features

- Modern and responsive user interface
- Product catalog with product images and pricing
- Product search functionality
- Category-based product filtering
- Product sorting by price, name, and newest
- Product Quick View modal
- Product quantity selection
- Add to Cart functionality
- Shopping cart quantity controls
- Remove products from cart
- Automatic cart total calculation
- Wishlist functionality
- Cart and wishlist data saved using Local Storage
- Demo checkout form
- Order confirmation screen
- Responsive navigation for mobile devices

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- React Hooks (useState and useEffect)
- Browser Local Storage

## 🚀 Run Locally

To run this project on your computer:

1. Clone the repository:

   ```bash
   git clone https://github.com/Mubeenasif10/luxecart.git
   ```

2. Navigate to the project folder:

   ```bash
   cd luxecart
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 🏗️ Production Build

To create an optimized production build:

```bash
npm run build
```

## 💳 Checkout Notice

LuxeCart currently includes a demonstration checkout experience. It does not process real payments or connect to a live order management system.
